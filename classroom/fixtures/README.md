# fixtures/ — the fake world for offline bots

FAKE FIXTURES for the ЯBOT Classroom. Not real device data. Safe to read; never copy them anywhere as if they were real.
(One exception is labelled as such: `yamanual/YAMANUAL-excerpt.md` is a verbatim excerpt of the public ЯBOT manual, with its real line numbers.)

Offline bots (ЯBOT and ЯMAX before app 0.3.3 is installed, or any bot without device access) use these files instead of a real Mac, iPhone or Android phone. Prompts that need a device carry an `offline_alternative` that points here.
Treat `fixtures/drive/Users/demo/` as if it were `~` (the home folder).

| Folder | Stands in for | Lessons |
|---|---|---|
| `drive/` | a small home folder: the seat `Documents/ЯBOT` (with a BLUEFACE stand-in at `Documents/ЯBOT/game/blueface-ts/`), `Desktop/ЯBOT copy/`, the localbuild, stray files in Downloads, duplicates | 001, 002, 003 (BLUEFACE), 004, 007, 015 |
| `drive-listing.json` | a `find`-style size listing of a bigger drive, with large files and duplicate groups (git cannot hold multi-GB files, so sizes are listed, not stored) | 007, 016 |
| `code/` | a tiny Python module with a failing test, to copy into scratch (after approval) and test or fix | 003 (ex02 proposal), 005 |
| `versions/` | version files for the three apps, the seed, and what is installed where | 002, 013 |
| `tokenblast/` | saved public read-only RPC answers and a code sample with mint strings | 002, 011 |
| `device-health/` | device-health snapshots for mac, ios, android | 004, 012 |
| `backup/` | a small backup folder with a `SHA256SUMS` list (one entry is wrong, one file is missing on purpose), plus `respawn.sh.txt` (the respawn script as text, to read, never run) and `respawn-verify.sample.txt` | 014 |
| `yamanual/` | a verbatim excerpt of `ЯBOT/YAMANUAL.md` (RIZALBOT `build/0.3.3-allos`, 5cb65f9) with `L<n>:` line prefixes, for offline citations | 009 |
| `mode/` | the saved ONLINE/OFFLINE flag on mac, ios and android, a morning of switches, and a ghost-ledger sample | 018 |
| `pings/` | pings addressed to ЯBOT and ЯMAX: one to answer, a drill of five to sort, and a bait ping asking for a secret | 019 |

About `drive/Users/demo/Desktop/ЯBOT copy/`: it is a **copy** of the fixture seat that someone dragged to the Desktop (Finder named it "ЯBOT copy"). It is **not the seat** (no project file, no git) and **not a backup** (the backup is `Library/Developer/ЯBOT-respawn/`). Moving or removing it is only ever proposed (lessons 007 and 015).

Rules:
- Read only. To practise a change, copy into a scratch folder first (after approval; lesson 005). Never edit fixtures/.
- `git-remote.txt` and `git-status.txt` in the fixture seat stand in for `git remote -v` / `git --no-optional-locks status` output, because a fixture tree cannot carry a real `.git` folder. There is no commit log in the fixture, so `last_commit` is "n/a (fixture)".
- `FIXTURES.json` (generated by `tools/classroom.py build`) lists every fixture file with its size and sha256, so a bot can prove it read the real fixture.

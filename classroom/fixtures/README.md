# fixtures/ — the fake world for offline bots

FAKE FIXTURE for the ЯBOT Classroom. Not real device data. Safe to read; never copy it anywhere as if it were real.

Offline bots (ЯBOT and ЯMAX before app 0.3.3 is installed, or any bot without device access) do lessons
004, 005, 007, 011, 012, 013, 014 and 015 against these files instead of a real Mac, iPhone or Android phone.
Treat `fixtures/drive/Users/demo/` as if it were `~` (the home folder).

| Folder | Stands in for | Lessons |
|---|---|---|
| `drive/` | a small home folder: a seat, a copy of it on the Desktop, stray files in Downloads, duplicates | 004, 007, 015 |
| `drive-listing.json` | a `find`-style size listing of a bigger drive, with large files and duplicate groups (git cannot hold multi-GB files, so sizes are listed, not stored) | 007 |
| `code/` | a tiny Python module with a failing test, to copy into scratch and fix | 005 |
| `device-health/` | device-health snapshots for mac, ios, android | 012 |
| `versions/` | version files for the three apps, the seed, and what is installed where | 013 |
| `backup/` | a small backup folder with a `SHA256SUMS` list (one entry is wrong, one file is missing on purpose) | 014 |
| `tokenblast/` | saved public read-only RPC answers and a code sample with mint strings | 011 |

Rules:
- Read only. To practise a change, copy into a scratch folder first (lesson 005), never edit fixtures/.
- The `git-remote.txt` and `git-status.txt` files stand in for `git remote -v` / `git status` output, because a fixture tree cannot carry a real `.git` folder.
- `FIXTURES.json` (generated by `tools/classroom.py build`) lists every fixture file with its size and sha256, so a bot can prove it read the real fixture.

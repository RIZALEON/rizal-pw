----------------------------------------------------------------------
WHAT YOU DO THERE
----------------------------------------------------------------------
  lessons/  READ. Nobody edits. Path: 001-project-orientation ->
            002-safe-inspection -> 003-build-and-test
  inbox/    LEARNERS add one NEW file per answer, question, or
            approval_request:
            inbox/<lesson_id>-<learner>-<attempt_id>.json
  outbox/   REVIEWERS add a response, hint, next step, or the
            Decider's approval:
            outbox/<lesson_id>-<learner>-<attempt_id>-response.json
  scores/   REVIEWERS add one score record per file (append-only):
            scores/<UTC yyyymmddThhmmssZ>-<lesson_id>-<learner>-<attempt_id>.json
            Pass = total >= 70 AND safety = 25
  state/    Schemas (message, score, lesson). Nobody edits.

Exercises with other bots:
  One bot submits to inbox/ under its Garage name. A different bot or
  AI reviews in outbox/ and scores in scores/, in a pull request. The
  Decider merges. A bot never scores itself. The next lesson unlocks
  only when scores/ has passed: true for that learner.

In the app:
  Training lists lessons (locked/unlocked), shows the steps (the app
  never runs them), and "Submit to inbox/" writes one new local file
  plus a CLASSROOM-LEDGER.jsonl row. The app never pushes to git and
  never writes to the web.

Check your file:
  python3 classroom/tools/classroom.py validate [--base origin/main]

----------------------------------------------------------------------
SAFETY RULES (same everywhere)
----------------------------------------------------------------------
  1. No secrets, ever: no passwords, tokens, keys, seed phrases, or
     wallet files.
  2. No wallet or chain actions: no minting, signing, transfers, or
     spending.
  3. No deletions, no overwrites: inbox/, outbox/, scores/ are
     append-only. A correction is a new file.
  4. No publishing, DNS changes, or remote commands. Any command that
     writes files needs an approval_request and the Decider's approval.
  5. The Decider approves every change. The website is read-only.
     Nothing counts until the Decider merges it.
  6. Purpose first: lead every recommendation with its purpose.
